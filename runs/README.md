# `runs/<run_id>/` — per-run generated artefacts (git-ignored)

Every training run writes into its own `runs/<run_id>/` directory so
multiple runs (sweeps, ablations, re-evals) coexist side-by-side
without clobbering each other.  The directory is **git-ignored
wholesale**; this README is the single tracked file under `runs/` and
exists purely to document the layout for reviewers who receive a
packed archive via `scripts/pack_run.sh`.

`run_id` is `<UTC>-<git-short-sha>`, e.g. `20260424T103055Z-a1b2c3d`,
generated by `core.runlayout.make_run_id`.  It is also derivable from
the environment via `KAGGLE2_RUN_ID` so `main.py`,
`scripts/eval_only.py`, etc. can target a previous run.

## Layout

```
runs/<run_id>/
├── metrics/          # scalar aggregates: combined_metrics.json,
│                     # assigner_metrics.json, pipeline_metrics.json,
│                     # cost_*.json, telemetry_*.jsonl, etc.
├── curves/           # per-epoch time series as CSV: donut_loss,
│                     # donut_lr, yolo_map, trocr_cer, gpu_util, ...
├── predictions/      # per-sample .jsonl: gt, pred, conf, edit_dist
├── attention/        # attention_samples.npz + meta JSON
├── figures/          # every PDF/PNG cited in paper_filled.tex
├── paper/            # paper_filled.tex / paper_filled.pdf / .log
├── env/              # git_sha.txt, pip_freeze.txt, nvidia_smi.txt,
│                     # config_snapshot.json, hostinfo.json
└── MANIFEST.json     # sha256 / size / mtime / producer for every file
```

Subdirectory names are defined in `core.runlayout.SUBDIRS`.  Writers
must use `core.runlayout.resolve_layout(runs_root, run_id)` to obtain
concrete paths — never hard-code strings under `runs/`.

## Pack / unpack round-trip

```
bash scripts/pack_run.sh                     # pack the latest run
bash scripts/pack_run.sh <run_id>            # pack a specific run
bash scripts/unpack_run.sh <archive>.tar.zst # restore + verify
```

`pack_run.sh` produces `<run_id>.tar.zst` plus a `.sha256` sidecar;
`unpack_run.sh` verifies both the archive sha256 and every per-file
sha256 against the restored `MANIFEST.json`.
