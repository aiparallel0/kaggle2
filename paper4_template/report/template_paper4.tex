\begin{abstract}
Structure-Verified Document Key-Information Extraction (SVKIE)
attains high macro-F1 on receipt benchmarks at the cost of an
upstream backbone with $\sim$260\,M parameters (DONUT) or
$\sim$133\,M parameters (LayoutLMv3-base).  Both exceed the
$\sim$67\,M-parameter budget of a deliberately-non-learned modular
pipeline.  We ask whether parameter-efficient compression
techniques --- int8 / int4
quantization~\cite{frantar2023optq,dettmers2023qlora}, structured
pruning~\cite{ma2023llmpruner}, and half-depth
distillation~\cite{hinton2015distilling} --- can place a
structurally-verified end-to-end system at the same on-device
memory footprint as the modular pipeline without sacrificing F1.
We define \textbf{compression crossover} as the simultaneous
satisfaction of (effective-memory $\leq$ pipeline-baseline-MB) and
(macro-F1 $\geq$ pipeline-F1 $-$ bootstrap-CI-half-width).  We
release a working repository implementing the compression sweep
and the Pareto-frontier evaluation on canonical SROIE Task-3.
\emph{Empirical results in this manuscript are pending the next
vast.ai compression sweep; cells below report the expected
Pareto trajectory based on Pruna-OSS calibration data and are
flagged accordingly.}
\end{abstract}
