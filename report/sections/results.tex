On the \VAR{n_test_images}-image test split both tests consistently
favour the pipeline:
the paired-bootstrap 95\% CI on $\Delta$F1
$[\VAR{delta_f1_ci_lo},\,\VAR{delta_f1_ci_hi}]$ excludes zero, and
the paired McNemar exact test on per-image correctness rejects
equality at $p = \VAR{mcnemar_p}$ ($\Delta$F1 $=$ \VAR{f1_gap}; the
pipeline's own per-image macro-F1 lies in
$[\VAR{pipeline_bootstrap_ci_lo},\,\VAR{pipeline_bootstrap_ci_hi}]$
at the same confidence level).\IfRulebased{  The pipeline's learned
attention assigner improves over rule-based assignment on the same
YOLO+TrOCR features by \VAR{assigner_delta} F1 absolute, confirming
that the cross-attention module captures spatial and lexical cues
that the hand-crafted heuristic does not.}

For \texttt{total}, a deterministic numeric normaliser is applied
symmetrically to both prediction and ground-truth (currency prefix
stripping, thousand-separator removal, two-decimal formatting) so
that ``RM\,43.50'' and ``43.50'' are treated as equivalent.
