\section{Extended Results Tables}
\label{sec:results_tables}

This section collects the detailed quantitative tables that
Section~\ref{sec:results} cites for the \textbf{basic} (500\,/\,63\,/\,63 internal
split) variant of this paper.  All three arms are present
(DONUT vs YOLO+TrOCR+\emph{regex} vs GT-OCR$+$regex baseline) so
the contribution of the deterministic regex layer can be isolated
from the upstream OCR stack.  Numbers are sourced from
\texttt{runs/<run\_id>/metrics/} sidecars via the
\texttt{report.inject} substitution layer --- no literal constants
appear in this file.  Because the test set is internal these
numbers are \emph{not} comparable to the public SROIE Task-3
leaderboard; for that comparison see the advanced variant.  An
empty cell renders as a typed \texttt{\textbackslash
MissingCell\{key\}} marker (never a silent em-dash); every
unresolved key is enumerated in
\texttt{metrics/unresolved\_vars.json}.
