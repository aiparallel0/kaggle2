\section{Reproducibility Checklist}
\label{app:repro}

\begin{itemize}
  \item \emph{Code, data, and checkpoints.}  Released under the
        project repository; split JSON is persisted to
        \texttt{results/split.json} and loaded on every subsequent run.
  \item \emph{Seeds.}  Configurable through \texttt{config.seeds} (a
        list) and \texttt{config.n\_trials} (an int,
        $\le|\texttt{seeds}|$).  Reported headline:
        \texttt{seeds=\VAR{seeds_configured}},
        \texttt{n\_trials=\VAR{n_trials}}.  Switching to $n{=}5$ is a
        single configuration edit; no code changes.
  \item \emph{Hardware and runtime.}  RTX\,4090 (24\,GB), CUDA 12.x.
        Wall-clock and energy are logged to
        \texttt{results/telemetry\_\textless stage\textgreater.jsonl}.
  \item \emph{Statistical testing.}  Paired bootstrap CI on
        $\Delta$F1 (\VAR{bootstrap_n_iter} resamples at
        \VAR{bootstrap_ci_level} level) and McNemar's exact test on
        per-image correctness.
  \item \emph{Headline hyperparameters.}  Base learning rate
        $\eta=\VAR{lr}$ (encoder; decoder uses $\eta_d=\VAR{lr_decoder}$
        --- see Sec.~\ref{sec:donut_lr}); label smoothing
        $\varepsilon=\VAR{label_smoothing}$; KD weights
        $\lambda_\text{attn}=\VAR{kd_attn_weight}$,
        $\lambda_\text{logits}=\VAR{kd_logits_weight}$ (both currently
        zero in the shipped run, see
        Sec.~\ref{sec:kd-ablation}).  Best assigner validation loss:
        \VAR{assigner_best_val_loss} at epoch
        \VAR{assigner_best_epoch}.
  \item \emph{Hyperparameters (full).}  See Section~\ref{sec:results};
        the live \texttt{config.json} is the single source of truth.
\end{itemize}


\section{Raw Metrics (Four-Decimal)}
\label{app:raw}

Table~\ref{tab:headline} rounds to three decimals.  For reviewers who
want the full precision the harness emits, the underlying seed-42
values are:
DONUT F1 $=\VAR{donut_f1}$, NED $=\VAR{donut_ned}$, EM $=\VAR{donut_em}$;
Pipeline F1 $=\VAR{pipeline_f1}$, NED $=\VAR{pipeline_ned}$, EM $=\VAR{pipeline_em}$;
\IfRulebased{Baseline (GT-OCR stream) F1 $=\VAR{gtocr_rulebased_f1}$,
NED $=\VAR{gtocr_rulebased_ned}$, EM $=\VAR{gtocr_rulebased_em}$;
predicted-OCR rule baseline NED $=\VAR{rulebased_ned}$;}
$\Delta$F1 $=\VAR{f1_gap}$ (DONUT minus pipeline);
learned-vs-rule $\Delta$F1 $=\VAR{assigner_delta}$.
Paired-bootstrap CIs at \VAR{bootstrap_ci_level} confidence over
\VAR{bootstrap_n_iter} resamples: per-image macro-F1
$\Delta$F1 $\in [\VAR{delta_f1_ci_lo},\,\VAR{delta_f1_ci_hi}]$;
all-fields-EM $\Delta$EM
$\in [\VAR{delta_em_ci_lo},\,\VAR{delta_em_ci_hi}]$
(both vectors of length $n=63$ are persisted alongside
\texttt{combined\_metrics.json} for reviewer audit).
Artifact mode: \texttt{\VAR{artifact_mode}} (``full'' = headline run
including DONUT + pipeline + rule baselines; ``gtocr\_rulebased\_only''
= no-GPU fast-path that fills rule-baseline columns only).
The four-decimal numbers are persisted to
\texttt{results/combined\_metrics.json}; mean/std/CI fields are
populated automatically when \texttt{n\_trials}$\ge 2$.
