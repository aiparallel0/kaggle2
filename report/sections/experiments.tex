For the \texttt{TOTAL} field, we apply a deterministic numeric
normalizer symmetrically to predictions and ground-truth before
computing F1/NED/EM (currency prefix stripping, thousand-separator
removal, two-decimal formatting). This ensures the metric measures
semantic match, not incidental formatting differences such as
``RM 43.50'' vs.~``43.50''.

The rule-based row uses SROIE's gold-OCR box-file text as input to
\texttt{rule\_based\_assign}, isolating the assignment heuristic from
YOLO/TrOCR error propagation. When the artifact mode reported in the
metrics JSON is \texttt{\VAR{artifact_mode}}, only the rule-based row
contains measured values; the DONUT and Pipeline rows are placeholders
awaiting a GPU run with Hugging Face access.
