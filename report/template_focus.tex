\title{FOCUS: Matching DONUT with \VAR{param_ratio_phrase} of the Parameters
       --- A Reproducible YOLO\,$+$\,TrOCR\,$+$\,Attention Pipeline
       on the Canonical SROIE Task-3 Test Set}

\author{\IEEEauthorblockN{Anonymous}
\IEEEauthorblockA{Under review}}

\maketitle

\begin{IEEEkeywords}
Key Information Extraction, SROIE, ICDAR-2019 Task~3,
document understanding, attention, leaderboard reproducibility,
parameter efficiency, carbon accounting.
\end{IEEEkeywords}

\begin{abstract}
We compare an end-to-end sequence-to-sequence model
(DONUT, $\approx$200\,M parameters) against a modular
detect\,$\to$\,read\,$\to$\,assign pipeline (\textsc{focus}:
YOLOv8\,$+$\,TrOCR\,$+$\,learned cross-attention assigner,
$\approx$\VAR{pipeline_params_m}\,M$+$\VAR{assigner_params_m}\,M
parameters) on the
\emph{canonical} ICDAR-2019 SROIE Task-3 evaluation set: 626
official training receipts (split
\VAR{n_train_images}\,/\,\VAR{n_val_images} for early-stopping
validation) and the \emph{\VAR{n_test_images}} official held-out
test images released by the SROIE organisers.  This is the protocol
every public SROIE leaderboard entry uses, so our numbers are
directly comparable; no internal split, no leaderboard-incompatible
re-partition.  With $n_{\text{trials}}=\VAR{n_trials}$ DONUT
reaches a global token-F1 of \VAR{donut_f1:mean_std_pct1} and the
pipeline reaches \VAR{pipeline_f1:mean_std_pct1}
($\Delta$F1$=$\VAR{f1_gap}, paired bootstrap 95\%
CI \VAR{delta_f1_ci_lo}--\VAR{delta_f1_ci_hi}, McNemar
$p=$\VAR{mcnemar_p:p}).  The pipeline ships at
\VAR{param_ratio_numeric} of the DONUT parameter count and
\emph{matches and slightly exceeds} our re-implemented DONUT,
within the \VAR{n_test_images}-image bootstrap CI, while exposing
per-field attention maps the monolithic decoder cannot.  We release
the full reproducibility bundle (sha256-pinned dataset downloader,
env snapshot, MANIFEST, 13 silent-bug regression guards, complete
training/eval/paper auto-pipeline) so any GPU operator can rerun
every reported number end-to-end.
\end{abstract}
