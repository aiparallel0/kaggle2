% ``\MissingCell{<key>}`` — the typed sentinel emitted by
% :mod:`report.inject` when a \VAR{} placeholder did not resolve to a
% real measurement.  Renders as a small red typewriter ``?<key>`` so
% reviewers see exactly which producer failed; counted as a hard build
% blocker by :mod:`report.check_artefacts` unless ``<key>`` is on the
% allow-list in :data:`report.missing.MISSING_OK_PREFIXES`.  This
% replaces the silent ``---`` em-dash backstop that produced the
% v1–v3 em-dash regression cycle.
\newcommand{\MissingCell}[1]{%
  % \text{} wrap is mandatory: this macro is emitted by report/inject.py
  % for unresolved \VAR keys and may land inside $...$ math mode (e.g.
  % appendix.tex $=\VAR{gtocr_rulebased_f1}$).  \textbf/\texttt/\textsubscript
  % are text-mode-only commands; wrapping with \text{} (amsmath, already
  % loaded) auto-switches to text mode in both math and text contexts.
  \text{{\color{BrickRed}\textbf{\texttt{?}}\textsubscript{\tiny\texttt{#1}}}}%
}

% Graphics-path search list.  Figure emitters write PDFs to two
% locations across our two historical run layouts:
%   * legacy flat layout  → ``./results/fig_*.pdf``
%   * runs_root layout    → ``runs/<run_id>/fig_*.pdf`` (older "flat"
%                          emitters) and ``runs/<run_id>/figures/fig_*.pdf``
%                          (the Section-C emitters in
%                          ``report.figures_section_c``).
% We add every candidate relative to the filled-tex location so
% ``\includegraphics{fig_foo.pdf}`` resolves regardless of which mode
% produced the artefact.  The current directory ``{}`` is included
% first so an explicit path in the caller still wins.
\graphicspath{{}{./}{./figures/}{./results/}{../}{../figures/}{../results/}}

% Conditional figure inclusion.  ``\iffigurefile{path}{body}`` expands
% to ``body`` when ``path`` is found by ANY of the graphics-search
% candidates above (not just the working directory), otherwise expands
% to an empty string.  ``\IfFileExists`` itself only consults
% kpathsea, so we repeat the candidate list explicitly — keeping this
% macro in sync with ``\graphicspath`` above is important.  Used by
% every figure caption so missing PDFs degrade gracefully: no empty
% floats, no LaTeX errors.
%
% ``\figref{fig:X}`` is the prose-side companion: it expands to
% ``\ref{fig:X}`` when the label was recorded in the previous compile
% pass, and to ``\textit{[figure absent]}`` otherwise.  Without this
% every ``\ref{fig:X}`` pointing at a label defined inside an
% ``\iffigurefile`` body would print as a bold ``??`` when the figure
% is not available — the classic "unprofessional partial-run PDF"
% symptom.  (Requires two pdflatex passes; tectonic and our pdflatex
% helper both already run the required number of passes.)
\makeatletter
\newcommand{\iffigurefile}[2]{%
  \IfFileExists{#1}{#2}{%
    \IfFileExists{./#1}{#2}{%
      \IfFileExists{./figures/#1}{#2}{%
        \IfFileExists{./results/#1}{#2}{%
          \IfFileExists{../#1}{#2}{%
            \IfFileExists{../figures/#1}{#2}{%
              \IfFileExists{../results/#1}{#2}{}%
            }%
          }%
        }%
      }%
    }%
  }%
}
\newcommand{\figref}[1]{%
  \@ifundefined{r@#1}{\textit{[figure absent]}}{\ref{#1}}%
}
\makeatother

\title{End-to-End vs.\@ Pipeline Receipt KIE: DONUT
       Against YOLO+TrOCR+Attention on SROIE}

\author{\IEEEauthorblockN{Anonymous}
\IEEEauthorblockA{Under review}}

\maketitle

\begin{IEEEkeywords}
Key Information Extraction, SROIE, document understanding,
attention, reproducibility, carbon accounting.
\end{IEEEkeywords}

\begin{abstract}
We compare two architectures for Key Information Extraction (KIE) on
the SROIE receipt benchmark under a fixed 500\,/\,63\,/\,63
train\,/\,val\,/\,test split: an end-to-end sequence-to-sequence
model (DONUT, $\approx$200\,M parameters) and a modular
detect-then-read pipeline (YOLOv8\,$+$\,TrOCR\,$+$\,learned attention
assigner, $\approx$65\,M $+$ \VAR{assigner_params_k}\,K parameters).
With $n_{\text{trials}}=\VAR{n_trials}$ on 500 receipts, DONUT
reaches a global token-F1 of \VAR{donut_f1:mean_std_pct1} and the
pipeline reaches \VAR{pipeline_f1:mean_std_pct1}
($\Delta$F1 $=$ \VAR{f1_gap}, within the
$\pm 0.05$ width of a 63-image bootstrap 95\% CI).  Our attention
assigner --- a $\approx\VAR{assigner_params_k}\,$K-parameter
Transformer-encoder~$+$~cross-attention module with four learned
field queries, 6-d handcrafted text priors, and a multi-instance
negative-log pos-mass loss --- closes \VAR{assigner_delta} absolute
F1 over rule-based assignment and produces per-field attention maps
that the monolithic DONUT architecture does not expose.  We
catalogue thirteen silent implementation bugs we encountered,
characterise the structural failure mode of the address field in
pipeline systems, and publish full GPU telemetry alongside every
reported number (\VAR{donut_peak_vram_gb}\,GB peak VRAM,
$\sim$\$\VAR{donut_cost_usd} per DONUT run on an RTX\,4090).  The
training and evaluation harness is seed-parametric: a single
configuration knob (``n\_trials'') scales from the reported
$n{=}1$ point estimate to any number of seeds without code changes.
\end{abstract}
