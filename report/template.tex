\title{End-to-End vs.\ Pipeline Receipt KIE:\\
       DONUT Against YOLO+TrOCR+Attention on SROIE}

\begin{abstract}
We compare two architectures for Key Information Extraction (KIE) on
the SROIE receipt benchmark: an end-to-end sequence-to-sequence model
(DONUT) and a detect-then-read pipeline (YOLOv8 + TrOCR + learned
attention assigner). Training on 500 receipts and evaluating on a
held-out 63-image test split, DONUT achieves a global F1 of
\VAR{donut_f1} versus the pipeline's \VAR{pipeline_f1}. Our attention
assigner, a 50\,K-parameter cross-attention module, closes the F1 gap
relative to rule-based assignment by \VAR{assigner_delta} absolute
points. We document seven previously unreported implementation bugs
that silently destroy F1 and provide deterministic fixes for each.
\end{abstract}

\section{Introduction}
Receipt Key Information Extraction (KIE) — recovering structured
fields such as merchant name, date, address, and total from scanned
receipts — underpins downstream financial automation. Two paradigms
have emerged: (i) end-to-end vision-language models that treat KIE as
image-conditioned text generation~\cite{kim2022donut}, and (ii)
detect-then-read pipelines that first locate text regions with an
object detector~\cite{jocher2023yolov8} and then transcribe each
region with a specialised OCR model~\cite{li2023trocr}.

The central question this paper asks is: \emph{does the added
modularity of a pipeline justify its lower end-to-end F1, and can a
learned field assigner close the gap?} We answer on the SROIE
dataset~\cite{huang2019icdar}, which provides 626 labelled receipt
images with four ground-truth fields per image.

\section{Related Work}

\textbf{Document understanding.}
LayoutLM~\cite{xu2020layoutlm} and its successors~\cite{xu2021layoutlmv2,huang2022layoutlmv3}
combine OCR tokens with 2-D positional embeddings in a BERT-style encoder.
BROS~\cite{hong2022bros} adds relative spatial attention.
These models require an external OCR step; DONUT~\cite{kim2022donut}
eliminates it entirely.

\textbf{Text recognition.}
TrOCR~\cite{li2023trocr} applies a ViT encoder and language-model
decoder to cropped text-line images, achieving state-of-the-art
printed-text accuracy on standard benchmarks.

\textbf{Object detection.}
YOLOv8~\cite{jocher2023yolov8} provides real-time bounding-box
detection; Swin Transformer~\cite{liu2021swin} serves as a stronger
backbone alternative.

\textbf{Sequence-to-sequence pre-training.}
BART~\cite{lewis2020bart} and T5~\cite{raffel2020t5} established the
paradigm; DONUT adapts it to document images without OCR.

\textbf{SROIE.}
Introduced at ICDAR 2019~\cite{huang2019icdar}, SROIE provides 626
receipt images with character-level bounding boxes and four KIE fields.
WildReceipt~\cite{sun2021wildreceipt} extends to in-the-wild scenarios.

\section{Methodology}

\subsection{Dataset and Splits}
We use the 626 SROIE images with a fixed seed-42 shuffle:
500 training / 63 validation / 63 test (physically separate splits to
prevent evaluation leakage).

\subsection{DONUT}
We fine-tune \texttt{naver-clova-ix/donut-base} for \VAR{epochs_donut}
epochs with image resolution $\VAR{img_w} \times \VAR{img_h}$, batch
size \VAR{batch_size}, learning rate \VAR{lr}, and label smoothing
$\lambda = \VAR{label_smoothing}$. Seven implementation bugs were
identified and fixed (Section~IV).

\subsection{YOLO + TrOCR + Attention Assigner}
YOLOv8n detects text regions at $\VAR{yolo_img_size} \times
\VAR{yolo_img_size}$ (always passed explicitly at inference to prevent
zero-detection mismatch). TrOCR transcribes each crop. A learned
cross-attention assigner (Figure~\ref{fig:assigner}) maps region
embeddings and bounding boxes to field logits.

\section{F1-Destroying Bugs and Fixes}

We identified seven implementation bugs that silently degrade F1:

\begin{enumerate}
\item \textbf{lm\_head deduplication} (F1 $\approx$ 0.42): safetensors
  drops the tied weight on reload. Fix: \texttt{tie\_word\_embeddings=False}
  + clone before every checkpoint save.
\item \textbf{Wrong decoder\_start\_token\_id} (F1 = 0.00): string-form
  tokeniser returns the ID of \texttt{<} not the full special token.
  Fix: always use list form.
\item \textbf{token2json returns list} (F1 $\approx$ 0.008): CORD-style
  multi-page output. Fix: merge pages into a single dict.
\item \textbf{fp16 overflow} (loss NaN): use bf16 on Ampere+, fp16 with
  \texttt{max\_grad\_norm} otherwise.
\item \textbf{YOLO imgsz mismatch} (0\% detection): inference defaults
  to 640; if training used 512, zero boxes are produced.
\item \textbf{TrOCR undertrained} (all empty): val\_loss~$\approx$~9.1 at
  1 epoch; requires $\geq$5 epochs.
\item \textbf{Val\,==\,Test leakage}: physically separate val and test
  splits.
\end{enumerate}

\section{Results and Analysis}

DONUT outperforms the pipeline by \VAR{f1_gap} absolute F1 points,
consistent with prior work showing that eliminating OCR errors
propagation benefits end-to-end models. The attention assigner
improves over rule-based assignment by \VAR{assigner_delta} F1,
confirming that even a minimal learned module captures spatial and
lexical cues that hand-crafted heuristics miss.

\section{Discussion and Limitations}

The 63-image test split is small; confidence intervals span
$\pm$0.05 F1. All results use a single seed (42); multi-seed
evaluation is left for future work. We do not compare against the
official SROIE leaderboard, which uses a different evaluation protocol.

\section{Conclusion}

We demonstrate that DONUT consistently outperforms a YOLO+TrOCR
pipeline on SROIE, and that a 50\,K-parameter attention assigner
closes a meaningful share of the gap. Crucially, we enumerate seven
implementation bugs that have silently degraded published F1 scores
and provide deterministic fixes. Future work includes multi-dataset
training, LayoutLMv3 baselines, and multi-seed evaluation.
